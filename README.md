# Sarath Peringayi Suresh — Portfolio

A graph-led portfolio for applied AI, analytics and data products. Built with static HTML, CSS and JavaScript; no build step or dependencies.

## Preview

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. The site can be served directly from the repository root by GitHub Pages.

## Design

The Evidence Engine illustrates sources → checks → interpretation → action. Its stage controls highlight the graph and explain the approach. Project graphs are conceptual illustrations, explicitly separated from the reported results.

The original data.lab palette is retained: near-black navy (`#07090f`), cyan (`#00e5ff`), green (`#00ffa3`), with pink and amber accents. Google Fonts are optional enhancements; system and Georgia fallbacks remain available.

Native project disclosures and anchor navigation work without JavaScript. The mobile menu, Stockholm clock and graph controls progressively enhance the page. Reduced-motion preferences disable transitions and smooth scrolling.
